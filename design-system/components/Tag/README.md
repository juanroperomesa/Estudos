# Tag

Etiqueta em pílula para categorias e filtros, com as variantes default e brand. Pode ter um botão de remover.

**O que você fornece**
- `children` com o rótulo e `variant`. Passe `onRemove` para mostrar o botão "×" (o nome acessível é "Remover").

**Regras**
- Padding `component-tag-padding-y` 4px / `component-tag-padding-x` 8px, raio `component-tag-radius`, texto em `label-md`.
- Use Tag para classificar conteúdo. Para status, use Badge.
